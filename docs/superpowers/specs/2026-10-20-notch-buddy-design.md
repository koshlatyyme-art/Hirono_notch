# NotchBuddy — живой персонаж в челке MacBook + история буфера обмена

## Context

Пустая папка `/Users/kaslatyj/Downloads/NOTCH`: только `character.png` (3D-рендер фигурки 932×1307, RGBA, глаза закрыты, в поднятой руке зелёный инопланетянин, на голове антенна с красным шариком, на груди красное сердце) и `glow.jpeg` (та же фигурка в темноте: светятся сердце и антенна). Машина: MacBook Pro 16" (3456×2234, есть челка), macOS 26.7, Xcode 27.1, Swift 6.4; Blender установлен, Pillow/OpenCV — нет.

Зачем: пользователь хочет, чтобы в челке **жил** персонаж (не статичная картинка: следит за курсором, реагирует на клики и другие события, шевелится сам) и чтобы челка была **полезной** — хранила последние 10 скопированных элементов за сессию (текст, ссылка, картинка) с удобным выбором любого из них.

## Цели / не-цели / анти-цели

**Цели**
1. Персонаж максимально похож на `character.png` и ощущается живым.
2. История буфера: до 10 элементов за сессию; клик — копирует обратно, элемент можно перетащить в другое приложение.

**Не-цели (v1):** сохранение истории на диск, синхронизация, настройки/окно преференций, App Store, распространение (фигурка — чужой дизайн, только личное использование), автоматическая вставка (Cmd+V пользователь жмёт сам), файлы из Finder.

**Анти-цели (провал, даже если «работает»):** персонаж выглядит как вырезанная аппликация с видимыми швами; дёрганая/механическая анимация; приложение заметно ест CPU/батарею; челка мешает кликать по меню-бару и окнам под ней; история сохраняет пароли.

## Решения пользователя
- **Размещение:** в свёрнутом виде — «уши» челки в границах меню-бара: слева **портрет по плечи** (голова, антенна, инопланетянин в поднятой руке; ~30pt по высоте, ≈35pt по ширине), справа счётчик элементов буфера. Наведение → челка раскрывается в панель: персонаж **целиком** (~90–110pt) слева, список буфера справа. Следствие: в свёрнутом виде реакции выражаются головой, антенной и инопланетянином; вспышка сердца и прыжок всем телом видны в раскрытой панели (в свёрнутой — прыжок портрета вверх-вниз).
- **Графика:** «воссоздать с максимальным сходством и оживить» — способ оставлен мне.
- **Выбор элемента:** клик копирует обратно в буфер + элемент можно перетащить мышью в другое приложение.
- **Поведение персонажа и допущения ниже — подтверждены («Всё так»).**

## Подтверждённое поведение персонажа
- **Курсор:** голова/корпус плавно тянутся в сторону курсора; чем ближе курсор к челке — тем внимательнее (выпрямляется). Курсор прямо над ним — ёрзает («щекотно»).
- **Клик где угодно:** лёгкое вздрагивание, мигает шарик антенны.
- **Клик по нему:** подпрыгивает, сердце вспыхивает, инопланетянин машет.
- **Cmd+C:** инопланетянин «ловит» копию (короткая анимация), счётчик справа +1.
- **Сам по себе:** постоянное «дыхание»; раз в 15–40 с случайное действие (потянулся, покачал головой, инопланетянин поёрзал); антенна пружинит после любого движения.
- **~5 минут без активности:** засыпает (голова опускается, «z»), просыпается от движения курсора.
- **Ночь:** сердце и антенна мягко светятся, как на `glow.jpeg`.
- Правый клик по персонажу → меню «Очистить историю», «Выйти».

## Мои решения (можно оспорить при чтении)
1. **Стек:** нативно, Swift 6 + SwiftUI + AppKit, SwiftPM-пакет (логика в библиотеке с тестами, тонкий исполняемый таргет), `.app` собирается скриптом. Подпись — существующим сертификатом «Apple Development» из связки ключей (стабильная подпись, чтобы разрешение на буфер не сбрасывалось после каждой пересборки). Без Dock-иконки (`LSUIElement`). Минимальная ОС — macOS 15.
2. **Персонаж = «кукла» из оригинального рендера (2.5D, как Live2D-lite).** Не перерисовываем и не моделируем в 3D (3D-копия с нуля будет заметно менее похожа). `character.png` режется на слои с точками вращения, перекрытые места дорисовываются. Поворот «к курсору» = наклон + сдвиг + `rotation3DEffect` по оси Y с перспективой (без Metal-шейдеров: Metal Toolchain на машине не установлен, и он не нужен); боковых ракурсов нет.
3. **Разрешения:** курсор — `NSEvent.mouseLocation` / глобальный монитор мыши, бездействие — `CGEventSource.secondsSinceLastEventType`: «Универсальный доступ» не нужен. Cmd+C — опрос `NSPasteboard.changeCount` (без перехвата клавиш). **Но** чтение содержимого буфера в фоне на macOS 15.4+ вызывает системный запрос доступа к буферу (`NSPasteboard.accessBehavior`) — один раз ответить «Разрешать всегда» (или в Системных настройках). Без этого история буфера технически невозможна. При `accessBehavior == .alwaysDeny` персонаж всё равно реагирует на копирование (changeCount), а в панели показывается подсказка, где включить доступ.
4. **Сессия** = до выхода из приложения, только в памяти. Повторная копия того же содержимого поднимает элемент наверх (без дублей). Элементы с `org.nspasteboard.ConcealedType` / `TransientType` (менеджеры паролей) игнорируются.
5. **Ночь** = 21:00–07:00 по локальному времени. Вид — как на `glow.jpeg`: все слои затемняются (~35% яркости, холодный оттенок), поверх аддитивно (`.plusLighter`) светятся сердце (тёплый оранжевый, с мягким пятном света на одежде), шарик антенны (оранжевый), синяя трубка (ярко) и зелёная (слабо). Это те же слои + цветовой фильтр и оверлеи, без отдельного набора графики.
6. **«Уши» и меню-бар:** уши узкие (≈ ширина портрета слева, ≈ ширина счётчика справа), правое ухо скрыто, пока история пуста. Раскрытие — после ~200 мс наведения на форму челки (чтобы не срабатывать, когда тянешься к соседним иконкам меню-бара). Вне формы все клики проходят насквозь.
7. **Экран:** окно на экране с челкой (`safeAreaInsets.top > 0`); если такого нет (крышка закрыта) — «искусственная» челка стандартного размера сверху по центру главного экрана.
8. **Раскрытая панель:** вертикальный список, строка ~40pt, видно ~5, остальное прокруткой; после клика по строке — короткая отметка «Скопировано», панель не закрывается. Закрытие — через ~300 мс после ухода курсора, **но не во время перетаскивания** (иначе исчезнет источник drag). Панель принимает первый клик без активации (`acceptsFirstMouse`), чтобы клик и drag работали, не перехватывая фокус у текущего приложения.

## Оставлено исполнителю
Точные размеры/радиусы/тайминги пружин, конкретные полигоны масок и точки вращения, правила приоритета типов при неоднозначном содержимом буфера (с тестами на типичные случаи: текст из браузера, «Копировать изображение» в Safari, ссылка из адресной строки, скриншот Cmd+Ctrl+Shift+4), формат превью строк.

## Архитектура

```
NOTCH/
  Package.swift                     # targets: NotchBuddyCore (lib), NotchBuddy (exe), NotchBuddyCoreTests
  Sources/NotchBuddyCore/           # чистая логика, без AppKit-окон — покрыта тестами
    Clipboard/ClipboardItem.swift       # enum Kind { text, link(URL), image }, id, дата, contentHash
    Clipboard/ClipboardHistory.swift    # max 10, дедуп → наверх, clear()
    Clipboard/PasteboardSnapshot.swift  # абстракция над NSPasteboard (типы + данные) → классификация
    Character/Spring.swift              # пружина-демпфер для суставов (angle/offset)
    Character/Rig.swift                 # описание слоёв: имя, pivot, родитель, z-порядок (из rig.json)
    Character/BehaviorBrain.swift       # состояния: idle/attentive/tickled/reacting/sleeping; инъекция clock+random
    Notch/NotchGeometry.swift           # расчёт прямоугольника челки и «ушей» из safeArea/auxiliaryTop*Area
  Sources/NotchBuddy/               # AppKit/SwiftUI-клей
    App.swift                           # NSApplication, accessory policy
    NotchPanel.swift                    # NSPanel borderless/nonactivating, level .statusBar+1,
                                        # [.canJoinAllSpaces,.stationary,.fullScreenAuxiliary];
                                        # ignoresMouseEvents переключается по попаданию курсора в форму
    NotchView.swift                     # чёрная форма челки, свёрнуто/раскрыто (spring-анимация)
    CharacterView.swift                 # TimelineView + слои Image с rotationEffect(anchor:) + rotation3DEffect головы + ночной фильтр/свечение (.plusLighter)
    ClipboardListView.swift             # строки, клик → копия, .onDrag → NSItemProvider
    PasteboardWatcher.swift             # таймер 0.4 с по changeCount, игнор собственных записей
    InputMonitor.swift                  # курсор, глобальные клики, idle-время → BehaviorBrain
    Resources/Character/*.png, rig.json
  Tests/NotchBuddyCoreTests/        # Swift Testing
  tools/rig/                        # одноразовые скрипты нарезки (Python venv: Pillow + OpenCV inpaint)
  scripts/build-app.sh              # swift build -c release → build/NotchBuddy.app (Info.plist, codesign "Apple Development")
  docs/superpowers/specs/2026-10-20-notch-buddy-design.md   # этот дизайн (раздел выше)
```

Поток данных: `InputMonitor` и `PasteboardWatcher` → события → `BehaviorBrain` (цели для суставов + одноразовые реакции) → `Spring`-интеграторы в `TimelineView` → `CharacterView`. `PasteboardWatcher` → `ClipboardHistory` → `ClipboardListView` / счётчик.

**Энергия:** в свёрнутом виде анимация ≤30 fps, при спящем дисплее/экранной заставке — пауза; опрос курсора только пока окно видно. Цель: < 2–3% CPU в простое.

## Этапы реализации

0. **Сохранить дизайн** в `docs/superpowers/specs/2026-10-20-notch-buddy-design.md`.
1. **Риг персонажа (контрольная точка с пользователем).** В `tools/rig/` (venv, Pillow + OpenCV) по полигональным маскам вырезать слои: тело (с шарфом и ногами), голова (волосы, «мозг», трубки), антенна, рука с инопланетянином (сердце — не слой, а свечение); дорисовать перекрытые зоны (`cv2.inpaint` + ручная доработка), записать `rig.json` (pivot: шея, плечо, основание антенны; прямоугольник кадра «портрет по плечи» для свёрнутого вида — один и тот же риг рендерится в двух кадрах).
   → verify: (а) композит в позе покоя ≈ оригиналу (PSNR > 40 dB) — проверка, что ничего не потеряно; (б) **главное — позы на крайних углах** (голова ±max, рука ±max, антенна ±max, сон): автоматически — внутри силуэта нет прозрачных «дыр» и резких швов (альфа-покрытие объединения слоёв ⊇ эрозия исходного силуэта); визуально — лист этих поз в кадре «портрет» на ~30pt и «целиком» на ~100pt (оба @2x) и крупно показать пользователю и получить «ок» до продолжения. Ночной вариант — на том же листе.
2. **Каркас + окно челки.** `Package.swift`, `NotchGeometry` (тесты на геометрию 14"/16"/без челки), `NotchPanel` с чёрной формой и пустыми «ушами».
   → verify: `swift test`; `scripts/build-app.sh && open build/NotchBuddy.app`; `screencapture -R` верхней полосы — форма сливается с аппаратной челкой, клики по меню-бару вне формы проходят.
3. **Буфер — ядро (TDD).** `ClipboardItem`, `PasteboardSnapshot`-классификация, `ClipboardHistory`.
   → verify: тесты: лимит 10, дедуп поднимает наверх, concealed/transient игнорируются, собственная запись не создаёт новый элемент, классификация текст/ссылка/картинка.
4. **Буфер — UI.** `PasteboardWatcher`, счётчик в правом «ухе», раскрытие по наведению, список, клик → копия, drag-out.
   → verify: `pbcopy`/копирование текста, ссылки, картинки (Safari, скриншот в буфер) → появляются в списке; клик → `pbpaste` возвращает выбранное; перетаскивание в TextEdit/Заметки вставляет текст/картинку; 11-я копия вытесняет самую старую.
5. **Персонаж — движок и поведение.** `Spring`, `Rig`, `CharacterView` (слои, 3D-поворот головы, свечение), `BehaviorBrain` (TDD: переходы по таймерам/событиям с фиктивными часами и random).
   → verify: тесты мозга (5 мин без событий → sleeping; движение курсора будит; клик по персонажу → reaction «jump»; Cmd+C → «catch»); вручную — каждое поведение из списка выше.
6. **Ночь, сон, полировка, энергия.** Свечение 21:00–07:00, «z» во сне, приоритеты реакций, пауза при спящем дисплее.
   → verify: подмена часов в отладке показывает ночное свечение; `ps -o %cpu -p <pid>` в простое < 3%; работа в полноэкранном приложении и при переключении Spaces.

## Verification (сквозная)
- `swift test` — все тесты ядра зелёные.
- `scripts/build-app.sh && open build/NotchBuddy.app` — приложение стартует без Dock-иконки; единственный системный запрос — доступ к буферу при первом копировании; после «Разрешать всегда» и пересборки запрос не повторяется.
- Ручной сценарий: подвигать курсор вдоль верха экрана (наклоны), кликнуть в разных местах и по персонажу, скопировать текст/ссылку/картинку (реакция + счётчик), раскрыть челку, кликнуть элемент и вставить Cmd+V, перетащить картинку в Заметки, оставить на 5 мин (сон), правый клик → «Выйти».
- Скриншоты свёрнутого/раскрытого состояния через `screencapture -R` для визуальной проверки.
